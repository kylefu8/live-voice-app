配置不作持久保存

生成二维码只在浏览器内完成。仅点击测试时，连接配置临时交给本机程序并请求所填服务，不记录密钥。清空或关闭页面会丢弃填写内容；下载文件需自行保管。

二维码可重复导入；撤销访问请在服务商处更换或停用 API key。
