# Live Voice PC 配置二维码

**简体中文** | [English](README.en.md)

在电脑浏览器里生成实际加密二维码。语音和后端配置可分别生成或合并，并各自提供真实连接测试；支持中英文、系统/浅色/深色主题。

**Android 0.2.0 及以上版本支持扫码导入**：打开“设置 → 扫码导入连接”，扫描后输入口令，核对地址并测试保存。电脑侧生成/解码测试与手机相机、真实服务验证分别记录。

## 打开

Windows 双击 `Open-QR-Tool.cmd`：使用项目内 Node 24（找不到时使用 PATH 中的 Node），在后台启动只监听 `127.0.0.1:8792` 的本机工具并打开默认浏览器。重复打开会复用当前服务，不改系统执行策略。

也可在本目录运行：

```powershell
.\start.ps1
```

再打开 <http://127.0.0.1:8792/>。此方式 Ctrl+C 即可停止。本机依赖已安装；其他已安装 Node 22+ 的机器先在本目录运行 `npm ci --ignore-scripts`，再运行 `node server.mjs`。浏览器使用新版 Chrome 或 Edge。二维码生成不依赖联网或 CDN；连接测试需要电脑能访问所填服务。请通过上述本机地址打开，不直接双击 HTML。

## 使用

1. 选择语音、后端或两者，分别填入完整 HTTPS API 基础地址、模型/部署名、鉴权方式和完整 API key。
2. 设置至少 4 个字符的自定义导入口令并重复确认；不足 4 个字符或全空白时不可生成。已有二维码仍兼容原口令解密。
3. 点击“生成加密二维码”，保留屏幕或保存 PNG。任何配置修改都会清除旧二维码，避免扫描过期配置。
4. 后续支持导入的手机版本中，扫码、输入相同口令、核对地址，再由用户测试并保存。生成本身不证明服务或 key 可用。

可先在每组配置下点击“测试语音连接”或“测试后端连接”，无需导入口令。测试使用当前草稿，不自动保存配置或生成二维码；取消、清空、修改对应字段或离开页面会取消等待，迟到结果不会覆盖新配置。未选中的连接不测试。测试结果只说明本次电脑到服务的连通情况。

“填入虚构示例”只填 `example.invalid` 和 `demo-` 测试值，不自动发起模型请求；点击测试不会让虚构地址变成可用服务。不要在对话里发送真实 key。

## 连接测试

- **语音**：电脑本机用 WebSocket 连接所填 HTTPS 基础地址对应的 `/live/sessions`，发送 `session.start`，收到 `session.started` 后立即 `session.close`，只在收到 `session.closed` 后显示通过。不使用麦克风或发送音频，不验证音频、打断或 Android 网络。某些服务不支持零音频探针，失败不能直接证明手机 WebRTC 不可用。
- **后端**：发送一次最小 Responses 请求，`store:false`，不启用搜索工具；需要实际模型响应，不能只凭模型列表或 HTTP 200 判定通过。响应未完成会单独提示。
- 两种测试可能产生少量服务用量。每次只使用所填 endpoint 和鉴权方式；不跟随重定向，不自动更换地址、key、模型或重试。
- Azure OpenAI 资源根地址会补上固定 API 前缀 `/openai/v1`，官方 OpenAI 根地址补 `/v1`；不改变目标主机，自定义网关路径保持原样。此规则与 Windows/Android 源码的实际会话路径一致；旧手机安装包应填写完整 API 基础路径。
- 结果区分鉴权、权限、模型不可用、接口不存在、配额、服务异常、超时和关闭未确认等固定提示；不把服务原始错误、key、地址或模型输出送回页面。
- 本机程序仅在用户点击测试时临时接收该组连接配置，并向所填服务请求；不记录请求体，不提供手机对话中转。导入口令和二维码加密仍只在浏览器内完成。

协议依据：[OpenAI Docs Live WebSockets](https://developers.openai.com/api/docs/guides/voice-websockets?api=live)，2026-09-20 核对。也沿用原生工程的 Responses 测试约定。

## 隐私与边界

- AES-256-GCM + PBKDF2-SHA-256（600,000 次），每次使用随机盐和 nonce；口令不包含在二维码中。格式与跨端固定测试向量见 [二维码协议](../design/config-qr-v1.md)。
- 页面没有分析脚本、外部字体或 localStorage/sessionStorage/IndexedDB 存储。CSP 只允许同源连接并禁止表单提交；本机服务只提供白名单静态文件和显式连接测试接口，不接收导入口令。
- 测试接口要求同源 Origin、JSON 和专用请求头，拒绝跨站调用；请求体最多 20KB，最多两项并发。断开页面请求会取消相应网络测试。只返回固定结果码和耗时，配置不写入文件或日志。
- 输入只暂留当前页面内存；API key 采用密码框，仅另显示少量头尾用于确认，没有显示完整 key 或复制按钮。浏览器自身、扩展或设备所有者不在这个 UI 限制的防护边界内。
- “全部清空”清除表单与二维码，离开页面也会清除。关闭浏览器、清空表单并不会删除已经下载的 PNG；文件需要自行保管。JavaScript 无法承诺物理内存安全擦除。
- 二维码可重复使用，不是一次性凭证；持有码与口令的人可解密。撤销需要在模型服务商处更换或停用 key。
- 一张二维码最多 1,800 个 ASCII 字符，使用 M 纠错与四模块白边，不覆盖 Logo。超长时明确拒绝，建议分开生成两组，不截短 key。
- 仅包含连接信息，不改变手机的会话偏好、模型参数或后端启用开关。PC 不是对话中转服务，导入后可关闭。
