# Android 发布签名切换

**简体中文** | [English](SIGNING-TRANSITION.en.md)

从 **0.5.0-2** 开始，公开 Android 包使用独立发布密钥，旧内部测试包使用的调试密钥不再用于公开发行。

**已有内部测试版的用户：先保留原应用，不要为了安装新版卸载或清除数据。**
Android 不允许不同签名的包直接覆盖安装；卸载可能删除本机文字历史、录音和配置。
本次发布没有自动迁移这些数据，也不会主动更新你的已有安装。旧应用仍可继续使用。
如需迁移，请先与维护者确认数据保留方案，再进行安装。

新用户可以正常安装公开 APK。后续使用同一正式签名的新版本可覆盖升级。
二维码只迁移模型连接配置，不迁移历史或录音。Windows 和 iOS 不受这次 Android 签名切换影响。
