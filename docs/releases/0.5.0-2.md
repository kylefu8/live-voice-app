# Live Voice for GPT-Live-1 — Mobile 0.5.0-2 / Windows 0.2.0-2

## 简体中文

首个经过公开前清理的源码快照与安装包，面向 GPT-Live-1 实时语音模型。

- Windows：下载 `live-voice-windows-0.2.0-2-x64.zip`，完整解压后运行 `Live Voice.exe`。便携包未进行代码签名。
- Android：下载 `live-voice-android-0.5.0-2-arm64-v8a.apk`。**旧内部测试版不能直接覆盖，请先阅读[签名切换说明](https://github.com/kylefu8/live-voice-app/blob/main/docs/SIGNING-TRANSITION.md)，不要卸载丢失数据。**
- iOS：从源码使用 Mac/Xcode 自行签名安装；无通用 IPA、App Store 或 TestFlight 下载。

本次更换 Android 发布签名，去除构建机地址，补齐第三方许可随包分发，并使用干净的 Windows 暂存目录。
不改变会话协议和数据格式。附件提供 `SHA256SUMS.txt`、项目许可证和 `THIRD-PARTY-NOTICES.txt`。

[使用方法与截图](https://github.com/kylefu8/live-voice-app#readme)。个人非商业使用免费，商业用途须事先授权，模型费用由所配置服务计费。

## English

The first cleaned public source snapshot and distribution for the GPT-Live-1 real-time voice model.

- Windows: extract `live-voice-windows-0.2.0-2-x64.zip` fully and run `Live Voice.exe`. The portable build is unsigned.
- Android: install `live-voice-android-0.5.0-2-arm64-v8a.apk`. **Internal test builds cannot update directly. Read the [signing transition](https://github.com/kylefu8/live-voice-app/blob/main/docs/SIGNING-TRANSITION.en.md); do not uninstall and lose local data.**
- iOS: build/sign with Mac and Xcode. No general IPA, App Store, or TestFlight distribution.

This release uses a separate Android signing key, removes the build host address, bundles third-party notices,
and packages Windows from a clean staging directory. Conversation protocols and data formats are unchanged.
See `SHA256SUMS.txt`, the license attachments, and `THIRD-PARTY-NOTICES.txt`.

[Setup and screenshots](https://github.com/kylefu8/live-voice-app/blob/main/README.en.md).
Noncommercial use is free; commercial use requires prior authorization. Model usage is billed by your service.
