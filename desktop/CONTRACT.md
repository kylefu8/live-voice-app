# Windows validation build contract

Approved: Electron Windows client, same functional scope as Android; local histories stay on each device. The client exposes one natural conversation experience; the former practice mode remains accepted only for migration and IPC compatibility. Phone linking only exports encrypted connection configuration, with >=4-character passphrase; no cloud sync or conversation relay. Android 0.2.0 supports camera import from Settings.

## File ownership

- Primary: main.mjs, preload.cjs, package/build/launch scripts, security wiring, docs and final integration.
- Services worker: services.mjs, store.mjs and tests/services.test.mjs, tests/store.test.mjs only.
- Live worker: renderer/live.ts and tests/live.test.mjs only.
- UI worker: renderer/app.mjs, renderer/index.html, renderer/styles.css only.
- Do not edit native/, pc-config/, other workers' files, credentials or global settings. Sources there may be imported and bundled by the desktop build. No workers spawn agents.

## Data

New or missing backend preferences default to maxOutputTokens 32768 and webSearch true; explicit saved values are preserved. The mobile-only recordingEnabled preference is not exposed by Windows, which currently saves text history only.

Windows-only Settings.audio is {inputDeviceId:string,outputDeviceId:string}, each defaults to empty string (system default), bounded to512 non-control characters. IDs stay in local preferences and never enter QR export. UI audio draft is saved separately; createDesktopLive receives saved audioDevices snapshot. Explicit device choices never silently fall back. Settings audio tests are mutually exclusive, local-only, bounded, cancellable; stop on leaving page, starting a conversation, or closing the app.

Settings and record shapes match native/src/types.ts. Settings: locale zh/en, theme system/light/dark, mode general; voice {voice,tone,intonation,pace,minutes,instructions}; backend {enabled,effort,maxOutputTokens,webSearch,timeoutSeconds,instructions}. Defaults match native/App.tsx. Legacy settings with mode practice are migrated to general on load. All settings persist ONLY on explicit saves, except theme/locale actions; drafts must not silently persist with global changes. Record {id,mode,startedAt,durationSeconds,confirmedClose,title?,titleSource?:manual|auto,fragments:[{role,text,startMs,endMs}]}; titles are optional, single-line, non-empty and at most 60 Unicode code points. Legacy records may retain mode practice and remain readable, with no mode filter or label in the UI. Limit history to 50 records / 1MB total and bound fields like native storage. Credentials {endpoint,model,auth:bearer|api-key,apiKey}. Returned Connection is {endpoint,model,auth,keyMask}; never return apiKey.

## Preload bridge (window.liveVoice)

Each method returns Promise<{ok:true,value:any}|{ok:false,code:string}>. All errors are safe fixed codes, no raw provider or filesystem errors. No raw IPC or Node API exposed. Primary wraps thrown errors and validates IPC sender. Services methods return plain values / throw fixed-code errors; main adds envelope. Service module exports async createServices({dataDir,safeStorage,fetchImpl?,probeImpl?}) returning methods below plus dispose(). safeStorage provides isEncryptionAvailable(), encryptString(string):Buffer, decryptString(Buffer):string. Inject filesystem root for tests.

- bootstrap() -> {version:'<package.json version>',settings,connections:{voice:Connection|null,backend:Connection|null},history:Record[]}
- saveSettings({settings,applyBackendToSession?:boolean}) -> Settings (validate, persist atomically). Explicit true replaces the current session backend preferences for subsequent requests, only if the same session still exists after persistence. Ordinary/global saves do not alter active snapshots. In-flight backend requests and startup credentials retain their snapshots; enabling without a startup backend credential rejects before saving.
- saveConnection({kind,credential}) -> Connection. Empty apiKey retains existing key ONLY if normalized endpoint and auth unchanged. Entire credential encrypted using safeStorage, no plaintext file; encryption unavailable => fail closed. Never read credentials from environment/other projects.
- testConnection({requestId,kind,credential}) -> {ok:true,code:'voice_ok'|'backend_ok',durationMs}. Draft test resolves empty key by same rule without saving. Reuse pc-config/probes.mjs; requestId bounds and duplicate protection; max2 tests; cancellation cannot affect unrelated tests.
- cancelTest({requestId}) -> null
- createSession({attemptId,sdp,mode}) -> {sessionId,sdp,settings}. Single active session, saved credential/settings snapshot; validate SDP <=64KB. The legacy mode value practice is accepted and normalized to general. POST saved endpoint /live/sessions, session {model,instructions,audio:{output:{voice}},delegation:{type:'client'},store:false},transport:{type:'webrtc',sdp}. No raw key exposed. Reuse native/src/protocol.ts for instructions; redirects disabled, bounded JSON <=1MB, timeout30s. Cancel and late responses must not recreate abandoned sessions. Missing enabled backend credential rejects startup.
- cancelSession({attemptId}) -> null. Cancel HTTP creation/delegation and release snapshot, scoped by attempt ID; renderer owns session.close and WebRTC cleanup.
- finalizeSession({attemptId}) -> {confirmed:boolean}. Main process attaches a bounded sideband to its retained sessionId with the original credential snapshot. Sends one session.close; only session.closed is confirmation. At most one attempt per session, cancelled on session release. Renderer invokes after8s without primary confirmation, or immediately when its primary channel is already unavailable; all close callers share the15s total deadline.
- runBackend({attemptId,delegationId,history}) -> {text,sources:[{title,url}]}. Use snapshot backend credentials/preferences; single operation per session; bounded transcript input. Reuse pure native protocol helpers for backend instructions. Responses HTTP call, redirect disabled, store:false, limits/timeouts/preferences, text/sources extraction. No incomplete/empty responses reported as success. Renderer does not send endpoints or keys. disabled backend => fixed error backend_not_configured.
- cancelBackend({attemptId}) -> null
- saveHistory({record}) -> Record[] (only nonempty valid records, bounded/atomic; local text only). The record is written before an optional, cancellable, best-effort backend title request; title generation is used only when backend is enabled and configured, has a 20-second bound, sends only a 6000-code-point excerpt, and never blocks session close or app exit. Failure keeps the localized date fallback without retry.
- loadHistory() -> Record[]
- renameHistory({id,title}) -> Record[] (serial compare-and-set mutation; preserves list order and marks titleSource manual)
- deleteHistory({id}) -> Record[] (serial idempotent mutation; preserves remaining order and cancels pending auto-naming)
- exportQr({kinds:['voice'|'backend'],passphrase}) -> {payload:string,kinds}. Read saved credentials in main, call pc-config/crypto.mjs encryptConfig; passphrase >=4, never store it. Only encrypted payload leaves main.
- saveQrPng({dataUrl}) -> {saved:boolean}. Primary implements OS save dialog and bounded PNG validation; renderer encodes its own QR canvas, no arbitrary path or arbitrary bytes API.
- onClosing(listener) -> unsubscribe function. Main asks renderer to close session before window exit. Renderer invokes readyToClose() after cleanup; main force-closes after17s if unavailable (controller close timeout15s plus local history flush); repeated window close requests remain intercepted until final cleanup.
- readyToClose() -> null (primary)

Renderer imports drawQr from ../../pc-config/qr.mjs (bundled); main imports probes/crypto and native pure protocol helpers (bundled). All assets local, no CDNs. Electron BrowserWindow nodeIntegration:false, contextIsolation:true, sandbox:true, webSecurity:true; CSP connect-src none (network credentials stay main), media-src self blob; no arbitrary navigation/new windows. Allow audio capture only from the local app; no camera.

## Browser live controller

renderer/live.ts exports createDesktopLive({api,audio,callbacks,environment?}), where api is above envelope bridge; audio is HTMLAudioElement; environment optional injects navigator/RTCPeerConnection/MediaStream/timers for tests. Return {start(mode),close(),dispose(),setMuted(boolean),appendStyle(voicePreferences),updatePreferences({voice?,backend?})}. updatePreferences serializes changes, preserves voice ID, waits for exact style ACK, updates duration from original start, and changes renderer backend enablement for subsequent work. These return promises except dispose/setMuted. start(mode) requests audio only on user action; creates oai-events before offer; await ICE then api.createSession; apply SDP; await matching session.started before commands. Never send session.start over WebRTC. Browser audio tracks and srcObject implement playback.

callbacks: onStatus(status:'idle'|'connecting'|'connected'|'closing'|'closed'), onTranscript(fragment), onError(code), onBackendStatus('idle'|'working'|'done'|'error'), onSources(sources), onClosed({confirmed:boolean,record:Record|null}). record mode and timestamps from this session; coalesce bounded transcript fragments. Internal history max500 fragments,16K chars each,256K characters/session; retain the opening user anchor and adjacent answer plus latest user turn when pruning older middle fragments. Backend input uses up to500 retained items within256KiB UTF-8 JSON, with the same anchor/latest policy. Empty or failed startup yields null record. Auto limit starts on session.started (0=no app limit). close callers share one deadline and wait up to15s for session.closed then marks unconfirmed and releases media/peer/requests; dispose immediately releases locally and marks unconfirmed as needed. Every callback/timer checks attempt identity so old sessions cannot affect new ones. Stop tracks even when permission request completes after cancellation. Handle microphone denied, playback failure, peer/channel close/disconnect, late backend, invalid JSON. Delegation events follow native/src/live.ts and official protocol, including stale-work checks. Style append ack matches client_event_id, max length conservative per native helper. All errors fixed codes. Tests must not use real mic/services.

## UI

Desktop left navigation: Conversation, History, Settings. Phone linking is under Settings. Warm terracotta + ivory logo / dark theme. Full Chinese/English UI, no fixed conversation-language field. One conversation entry point with Start; connected status/timer, mute/end, always-visible captions. Only search sources can be expanded/collapsed, with collapsed as the default. Use masked saved keys and password editor with no reveal/copy. Independent connections/auth/model + save/test/cancel, backend effort includes max. Voice/style/minutes and backend prefs as native. During a connected call, explicit voice save updates supported style/instructions and duration after matching ACK; expiry remains anchored to original start and elapsed limits reject without closing. Voice ID remains immutable. Explicit backend save updates subsequent requests only. Connection management contains both connection forms and the phone QR export entry; conversation preferences contain no connection fields. Appearance/language and audio device settings have separate tabs. Calls can navigate to settings and back without being closed. History shows legacy and new records together without mode filters or labels, supports local rename and explicit delete confirmation, and never restores old context. Automatic title generation is disclosed in the history view. Phone linking selects saved configurations, >=4 passphrase + confirm, draw/download QR. Point Android 0.2.0+ users to Settings → Import connections from QR. No fake success, no mock bridge fallback in production; startup failure visible. Avoid innerHTML with user content; all dynamic content textContent. Catch rejected bridge/controller promises.

Verification: compile/package + local UI, simulated protocol/storage tests, start packaged executable. Actual provider, microphone/audio/barge-in quality need user configuration and separate verification; never label them passed from mocks.
