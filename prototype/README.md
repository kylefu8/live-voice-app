# Live Voice 可点击原型

**简体中文** | [English](README.en.md)

无构建依赖的浏览器交互原型，包含首页、演示对话、历史列表与详情、主题设置、语音与后端参数、扫码导入流程。

## 启动

在本目录运行：

```powershell
python -m http.server 8791 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8791/>。浏览器缩窄后呈现手机全屏布局，桌面显示预览面板。也可以直接打开 `index.html`；不同浏览器在本地文件下的存储行为可能不同，推荐使用本地服务。

## 可体验的流程

1. 选择“通用 / 练口语”，开始对话，点击“演示插话”查看回应与聆听状态切换；可静音、收起字幕、结束会话。
2. 从首页进入历史，按模式筛选，查看只读文字详情。结束后的演示记录也会出现。
3. 设置中切换跟随系统、浅色、深色；选择会保留到下次打开。
4. 调整语音或后端参数，离开页面再返回，未保存草稿仍在。保存后刷新可保留；正在进行的演示会话仍使用开始时的参数。
   - 语音页不设置对话语言，提供语气、语调、节奏；进行中的演示可以单独应用新风格，音色和总时长不随之改变。
   - 连接配置分别编辑语音与后端的 endpoint、模型、鉴权和示例 key。已保存 key 仅展示头尾遮罩，无明文和复制操作。
   - 两套连接配置分别提供“测试连接（演示）”：校验当前填写的配置，再模拟语音会话或后端响应，显示测试中、成功、失败。测试不自动保存；编辑配置会使旧结果失效。可点“查看连接失败状态”演示超时，再重试。
   - 后端支持选择 xhigh、max，另有 Token 上限、搜索、超时与后端指令。
5. 打开扫码更新，点击“使用示例二维码”。演示口令为 `preview`；可试错口令、查看核对页、模拟连接失败或完成流程。
6. 顶部语言选择或设置页切换中文、英文。界面切换不翻译历史原文，不丢弃参数草稿或重启演示。

## 原型边界

- 不调用模型，不发起 WebRTC，不访问麦克风或相机，不录音或播音。
- “演示插话”只验证控件与状态变化，不证明真实语音打断的速度和正确性。
- 扫码、解密与连接测试都是流程演示，没有实施二维码识别、AES-GCM 或凭据安全存储。`preview` 是流程样例，不是应用内置加密密码。
- `example.invalid` 地址是演示数据，不发送模型请求。手动输入的示例 key 必须以 `demo-` 开头且至少 12 字符；保存后只保留遮罩，原始输入随即丢弃。请勿输入真实凭据。
- 页面 CSP 禁止连接外部服务；静态文件、图标与字体均无第三方资源依赖。
- 界面语言、主题、保存后的参数、示例连接与 key 遮罩，以及最多 100 条示例记录保存在本浏览器的 `live-voice.interactive-prototype.v1` localStorage 项。完整 key 不保存。只有演示对话会生成新记录；这不是最终 App 的安全存储设计。
- 未保存参数草稿仅留在本次页面生命周期中，刷新会丢弃；主题切换、应用内返回和浏览器返回不会丢弃。
- 参数选项是示例，不代表任意部署支持对应音色、推理强度或搜索。
- 历史当前按文字设计；是否保存真实录音尚待确认。本原型没有历史继续对话、云同步或导出功能。

## 文件

- `index.html`：预览外壳及资源入口。
- `styles.css`：布局、主题、组件与动效。
- `app.js`：页面路由、演示状态、示例记录与参数草稿。
- `i18n.js`：中英文案与静态外壳翻译。

真实模型协议、Android 原生音频和加密导入仍按[项目规划](../README.md)分阶段验证。

已执行的浏览器检查和界限见 [VERIFICATION.md](VERIFICATION.md)。
