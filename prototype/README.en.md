# Live Voice interaction prototype

[简体中文](README.md) | **English**

This directory preserves an early browser interaction prototype for the Live Voice **GPT-Live-1 client**. It is a design/demo surface, not the production Windows app or mobile client. Simulated connection tests, sessions, and QR interactions are not evidence of real model connectivity.

For current installation and configuration, use the [getting-started guide](../docs/GETTING_STARTED.en.md), [Windows client](../desktop/README.en.md), or [mobile client](../native/README.en.md). The [screenshot gallery](../docs/SCREENSHOTS.en.md) shows the current production interface code with demonstration data.

The prototype supports Chinese/English and appearance variants for interaction review. Legacy practice/general-mode designs may appear in historical design assets; current production clients use one natural conversation entry point. Do not enter production credentials in a simulated flow.
