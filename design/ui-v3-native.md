# Android 0.3.0 界面与录音

本轮落实用户确认的首页、会话页和底部导航改进，延续陶土橙、暖白和深色主题。首页突出模式选择与开始按钮；对话、历史、设置有固定底部入口，活动会话可返回且切换导航不会主动结束。会话控制固定在字幕滚动区之外，支持字幕展开/收起，当前状态来自实际连接事件，不用装饰动效假装正在听或回应。

首页告知每次新会话自动录音，会话中显示录音或保存/失败状态。历史详情可播放、暂停、拖动进度、前后跳转 15 秒并删除录音。准备文件期间进度跳转不可用；删除有确认，保留尚在本机的文字。录音独立保留到手动删除，旧纯文字历史仍可阅读。

验收包括真机中英、深浅色布局，以及合成录音的播放、暂停、seek、删除。双方真实声音、耳机路由和说话打断仍需要真实会话验证；自动化 codec 测试不代替此项。录音存储和采集取舍见 [ADR 0002](../docs/adr/0002-android-local-recordings.md)。
